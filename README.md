# Ficha Técnica Pessoal

## Sobre o projeto

Este projeto é uma página pessoal desenvolvida durante as aulas de Desenvolvimento de Aplicações para Internet (DAI).

A página apresenta informações pessoais, hobbies, conhecimentos e um link para o Instagram. Também possui algumas interações utilizando JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Exibição de informações pessoais;
- Exibição de foto de perfil;
- Lista de hobbies;
- Lista de conhecimentos;
- Link para o Instagram;
- Alteração da cor do título;
- Mensagem de boas-vindas;
- Mensagem personalizada utilizando o nome informado pelo usuário.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` utilizando o Live Server.
4. A página será aberta no navegador.
